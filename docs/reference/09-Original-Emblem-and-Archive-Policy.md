# Failure is Not an Option — Original Emblem and Archival Footage

**Confirmed user direction:** Avoid NASA's logo in newly created game assets. Preserve logos already present within original opening footage; edit the selected clips without replacing or painting out those logos. Develop an original emblem that evokes the space-program setting.

## Approved emblem: Flight Operations

[SVG master — version 5](art/flight-operations-v005.svg) · [PNG preview — version 5](art/flight-operations-v005.png)

**Status: User approved version 5 as the game's stand-in for NASA's Meatball logo.** Use the linked version 5 SVG as the master and its transparent PNG for raster placement.

The approved design is a vertical blue oval with a gold border and globe grid, an elongated gold four-pointed star, and a white curved inverted V. The star's lower point overlaps the V's apex. There is no lettering. Versions 1-4 remain superseded working history and should not be integrated.

This is the fictional flight-control team's game emblem. It does not rename NASA or pretend to be a replacement official agency identity. NASA can still be named in ordinary narrative text, historical descriptions, acknowledgments, and the dedication. Do not render its name in the official logotype.

The concept avoids the circular blue insignia, red vector/swoosh, starfield-and-orbit arrangement, NASA lettering, worm logotype, and agency seal. Future mission patches should be original commemorative game designs and should not import those protected marks into generated portraits, clothing, or scenery.

The design is editable SVG with a transparent-background PNG preview. It has not undergone trademark clearance, and its distinct appearance is not a guarantee of legal clearance. Production export should verify the globe grid at small sizes; simplify grid lines where needed rather than shrinking them into noise. Any simplified embroidery or small-size variant should preserve the approved silhouette and colors.

## Use in the game

- Vests, fictional desk documents, menus, and generated room illustrations use the original game/team emblem or remain unbranded.
- Generate illustration with blank badge areas when practical, then place the approved emblem as a separate asset for consistency. Do not ask an image generator to invent a variation for each portrait.
- The game title and independent-project notice remain the public project identity. Do not suggest this departmental emblem is an authentic historical NASA badge.
- Credit it as an original fictional emblem designed for Failure is Not an Option.

## Opening footage

Preserve incidental NASA marks in the original archival clips. Do not replace, blur, repaint, or generatively reconstruct them. Normal clip selection, trimming, sequencing, and audio editing can proceed within the established opening treatment.

Keep original footage recognizable as archival material, with its source recorded. Do not extract its logo for standalone game branding. For the final transition into generated art, prefer an unbranded ending shot or let the archival image fully fade out before the illustrated room resolves. Do not morph an authentic insignia into the new emblem.

This separation implements the user's editorial decision; it does not declare all possible uses of an archival clip cleared. The individual footage sources and their credits remain part of the existing media review.
